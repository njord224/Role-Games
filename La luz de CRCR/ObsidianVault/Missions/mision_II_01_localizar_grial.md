# Misión II.01 - Localizar el Grial

## Descripción

El [[Players/player_sandra|Sandra]] asigna una misión encubierta para localizar el [[Materials/material_grial|Grial]] sagrado. Esta misión continúa la búsqueda de reliquias sin revelar el secreto.

## Asignador

[[Players/player_sandra|Sandra]]

## Asignados

Sandra puede asignar esta misión a un miembro de confianza, presentándola como parte de los preparativos normales.

## Materiales Requeridos

- **Mapa completo** - [[Materials/material_fragmentos_mapa]] (debe estar reunido)
- **El Grial** - [[Materials/material_grial]] (objetivo a encontrar)

## Condiciones de Éxito

El Grial es encontrado y recuperado.

## Condiciones de Fracaso

El Grial no es encontrado, complicando la recuperación.

## Cómo Se Completa

1. Sandra debe tener el mapa completo
2. El mapa revela la ubicación del Grial
3. El miembro asignado busca el Grial
4. El Grial es recuperado

## Interacciones que Crea

Sandra interactúa con el miembro asignado, manteniendo el secreto.

## Notas para el Master

- Segunda reliquia a recuperar
- El miembro asignado puede sospechar si el Grial no está donde debería estar
- Puede crear más tensión si se descubre la verdad
