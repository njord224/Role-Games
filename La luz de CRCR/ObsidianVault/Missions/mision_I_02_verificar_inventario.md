# Misión I.02 - Verificar Inventario

## Descripción

[[Players/player_pilar|Pilar (Mano Derecha 1)]] debe verificar que todos los elementos necesarios para la ceremonia estén presentes y en orden. Esta misión permite supervisar los preparativos y detectar cualquier anomalía.

## Materiales Requeridos

- Material listado en el inventario

## Cómo Se Completa

1. Revisar la lista de inventario
2. Conseguir cada uno de los elementos
3. Reportar cualquier discrepancia

## Notas para el Master

- Esta misión puede ser una "misión señuelo" que no revela el secreto de las reliquias
- Puede usarse para crear tensión si se descubren elementos faltantes
- Permite a Pilar ejercer autoridad
