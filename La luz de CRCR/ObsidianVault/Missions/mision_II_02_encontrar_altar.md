# Misión II.02 - Encontrar el Altar

## Descripción

El [[Players/player_sandra|Sandra]] asigna una misión encubierta para encontrar el [[Materials/material_altar|Altar]] sagrado. Esta es la tercera y última reliquia que debe ser recuperada.

## Asignador

[[Players/player_sandra|Sandra]]

## Asignados

Sandra puede asignar esta misión a un miembro de confianza.

## Materiales Requeridos

- **Mapa completo** - [[Materials/material_fragmentos_mapa]] (debe estar reunido)
- **El Altar** - [[Materials/material_altar]] (objetivo a encontrar)

## Condiciones de Éxito

El Altar es encontrado y recuperado.

## Condiciones de Fracaso

El Altar no es encontrado, lo que impide completar la ceremonia.

## Cómo Se Completa

1. Sandra debe tener el mapa completo
2. El mapa revela la ubicación del Altar
3. El miembro asignado busca el Altar
4. El Altar es recuperado

## Interacciones que Crea

Sandra interactúa con el miembro asignado.

## Notas para el Master

- Tercera y última reliquia
- Si las tres reliquias son encontradas, Sandra puede proceder con la ceremonia
- Puede ser el momento donde el secreto se revele si el miembro asignado sospecha
